# Crowds Implementation Plan

**Goal:** Spectators line the last stretch of every climb and the sprint lines, cheer riders coming by, wave flags, and come out in bigger numbers when more riders are online.

**Architecture:** Client only. Placement stays in `features.js` (seeded, built with the world); behaviour is a pure module (`crowd.js`) the view calls per frame. No server or protocol change.

**Spec:** `docs/superpowers/specs/2026-11-10-crowds-design.md`

## Global Constraints

- Branch `feat/crowds`, based on `origin/main`.
- The existing crowds keep their places and looks: new placement draws from its own random stream.
- `make check` before every commit.
