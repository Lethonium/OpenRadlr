# Ghost Lap Implementation Plan

**Goal:** A see-through rider replays my best lap on a loop route, with the live gap on the HUD.

**Architecture:** Client only. A pure module turns my position and the ride clock into laps and traces and keeps the best per route in IndexedDB; the views draw a rider marked `ghost`; `main.js` wires it into the ride. No server or protocol change.

**Spec:** `docs/superpowers/specs/2026-11-10-ghost-lap-design.md`

## Global Constraints

- Branch `feat/ghost-lap`, based on `origin/main`.
- UI text through `t()` with keys in `en.js` and `de.js`.
- `make check` before every commit.
