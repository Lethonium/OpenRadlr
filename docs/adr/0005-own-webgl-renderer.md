# 5. Own small WebGL renderer for the 3D view

Date: 2026-10-14 · Status: accepted

## Context

The POC needs a 3D view. The client has no build step and must work on a LAN
without internet access. The style is deliberately low-poly: flat-shaded
triangles, vertex colours, fog, a few hundred trees and a dozen riders.

## Decision

Render with a ~150-line WebGL 2 renderer (`client/public/js/view3d/renderer.js`)
instead of Three.js. Geometry is generated by pure, unit-tested functions; the
renderer only uploads buffers and draws them.

## Consequences

- No dependency, no CDN, no bundler; works offline from the game server.
- Geometry and camera maths are testable in Node without a GPU.
- Features like shadows, textures or model loading would need work. If the
  scene grows beyond that, switching to Three.js (or the native client's engine)
  only replaces `renderer.js` and `view3d.js`; the geometry builders stay.
