# 3. Key-based identity

Date: 2026-10-10 · Status: accepted

## Context

Riders should be able to use local profiles on any server, and optionally a
global account later — without every server calling a central service.

## Decision

A profile is an ECDSA P-256 key pair generated by the client. The public key is
sent with `join`. Servers have an `auth_mode`: `open` accepts anyone (the only
mode in the POC); a future `verified` mode accepts keys signed by the auth
server, checked offline with the auth server's public key.

## Consequences

- Local play needs no account and no internet.
- A global account is an add-on (a signature), not a different protocol.
- Paid access to official servers can later be enforced via `verified` mode.
