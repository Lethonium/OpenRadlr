# Name and logo

"OpenRadlr" and the lemon logo (the lemon in an aero helmet) identify this
project and the official server at openradlr.com. The code licence (AGPL) and
the artwork licence (CC BY-SA) give you broad rights to the code and the image
files; they do not give you the right to use the name or logo as the name or
logo of your own product or service.

## Fine without asking

- Saying what your server or fork is based on: "a fork of OpenRadlr",
  "runs OpenRadlr", "compatible with OpenRadlr".
- Running the unmodified software, or software with only configuration
  changes, under its own name and logo, e.g. a club server.
- Using the name and logo to talk about the project: articles, videos, talks,
  links.

## Please ask first

- Naming a modified version, a fork or a commercial service "OpenRadlr" or
  something easily confused with it.
- Using the logo as the logo or app icon of a modified version or a service.
- Merchandise with the name or logo.

A fork with real changes should pick its own name and icon, so riders can tell
which project they are using. Ask in a GitHub Discussion if unsure.
